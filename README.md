# Sobre Ruedas v2.9.0

Actualización de rediseño integral y refuerzo operativo.

## Accesos
- `index.html`: Sobre Ruedas para pasajeros.
- `conductor.html`: Sobre Ruedas Conductor.
- `admin.html`: Sobre Ruedas Admin.

## Instalación
1. Reemplazar todos los archivos del repositorio.
2. Ejecutar una sola vez `ACTUALIZAR_SUPABASE_v2.9.0.sql`.
3. Cerrar y volver a abrir la app para renovar la caché.

No ejecutar los SQL de `SQL_ANTERIORES`.
