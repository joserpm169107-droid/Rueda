# Rueda v0.1

Prototipo privado de una aplicación de transporte para Ciego de Ávila.

## Incluye
- Registro de pasajero
- Registro de conductor
- Selección de motorina, moto o triciclo
- Inicio y cierre de sesión
- Persistencia con Local Storage
- Diseño adaptable para iPhone

## Publicación
Sube `index.html` a la raíz del repositorio y activa GitHub Pages desde la rama `main`.
