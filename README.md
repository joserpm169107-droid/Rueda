# Sobre Ruedas v2.6.0

Actualización profesional de pasajero, conductor y administración.

## Incluye

- Aplicaciones de pasajero y conductor totalmente separadas.
- Diseño adaptativo para teléfono, tablet y computadora.
- Modo oscuro corregido en tarjetas, textos, mapa, navegación y ventanas.
- Buscador de direcciones con sugerencias, selección en mapa y cálculo de ruta.
- Navegación interna para conductor y accesos a Google Maps y Waze.
- Foto de perfil para pasajero y conductor.
- Foto e información completa del vehículo: tipo, marca, modelo, año, color, matrícula y capacidad.
- La información profesional del conductor se muestra al pasajero durante el viaje.
- La foto del pasajero se muestra al conductor durante la recogida.
- Panel administrativo con viajes, suspensión temporal, reactivación y eliminación definitiva para pasajeros y conductores.
- Suspensión por fecha libre, con motivo y cancelación de operaciones activas.
- Eliminación definitiva del perfil, fotos, viajes, reportes y eventos asociados.
- Auditoría administrativa sin conservar datos personales después de una eliminación definitiva.

## Instalación

1. Reemplaza en GitHub todos los archivos del proyecto con el contenido de este ZIP.
2. En Supabase abre **SQL Editor → New query**.
3. Ejecuta una sola vez `ACTUALIZAR_SUPABASE_v2.6.0.sql`.
4. No vuelvas a ejecutar los SQL guardados en `SQL_ANTERIORES`.
5. Espera a que GitHub Pages publique y recarga completamente la aplicación.
