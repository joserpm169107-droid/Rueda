# Panel administrativo beta

1. Ejecuta `CONFIGURAR_PANEL_ADMIN.sql` en Supabase SQL Editor.
2. Sube todos los archivos de este paquete a GitHub.
3. Abre `admin.html` desde la dirección de GitHub Pages.
4. Durante esta beta, el código temporal es `RUEDA2026`.

El panel muestra estadísticas, viajes en tiempo real, conductores, pasajeros, alertas y tarifas editables.

**Importante:** el acceso por código y las políticas abiertas son únicamente para pruebas. Antes del lanzamiento público hay que activar Supabase Auth, roles reales y políticas RLS privadas.
