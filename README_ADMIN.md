# Sobre Ruedas Admin v2.9.0

El panel usa la misma base de datos de pasajero y conductor. La v2.9.0 añade una identidad visual de centro de operaciones, soporte verificable y eliminación definitiva reforzada.

Ejecuta únicamente `ACTUALIZAR_SUPABASE_v2.9.0.sql`. Mantén el código administrativo privado. El acceso beta debe sustituirse por Supabase Auth antes de publicar el servicio.
